# SARS-CoV-2 Variant Analysis Using R

## Español

Este proyecto académico consiste en un **análisis bioinformático de distintas variantes del SARS-CoV-2 y otros coronavirus**, utilizando el lenguaje de programación **R** y bibliotecas especializadas en secuencias biológicas.

El trabajo se enfoca en comparar **secuencias genómicas en formato FASTA** para:
- Analizar la longitud de cada genoma
- Comparar la composición de bases nitrogenadas (A, C, G, T)
- Identificar similitudes y diferencias entre variantes
- Visualizar relaciones mediante análisis jerárquico

### Metodología general
- Lectura de secuencias genéticas (FASTA)
- Cálculo de la longitud de cada secuencia
- Conteo de bases de ADN por variante
- Visualización comparativa mediante gráficas de barras
- Construcción de un dendrograma usando distancias euclidianas
- Análisis jerárquico para observar relaciones globales entre variantes

### Tecnologías y librerías utilizadas
- R
- ggplot2
- seqinr
- ape

 **Nota:** Este proyecto es de carácter **analítico y académico**.  
El objetivo principal es la **exploración y comparación de datos genómicos**, no el desarrollo de una aplicación clínica o diagnóstica.

---

## English

This academic project presents a **bioinformatics analysis of multiple SARS-CoV-2 variants and other coronaviruses**, using the **R programming language** and specialized libraries for biological sequence analysis.

The study focuses on comparing **genomic sequences in FASTA format** to:
- Analyze genome lengths
- Compare nucleotide composition (A, C, G, T)
- Identify similarities and differences among variants
- Visualize relationships through hierarchical analysis

### General Methodology
- Reading genetic sequences (FASTA files)
- Calculating genome length for each variant
- Counting DNA bases per sequence
- Comparative visualization using bar charts
- Dendrogram construction with Euclidean distances
- Hierarchical clustering to observe global relationships among variants

### Technologies and Libraries Used
- R
- ggplot2
- seqinr
- ape

 **Note:** This is an **academic and analytical project**.  
Its purpose is focused on **genomic data exploration and comparison**, not on clinical or diagnostic applications.
