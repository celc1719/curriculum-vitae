# Buscaminas en Python (Consola)

## Descripción (Español)

Este proyecto es una implementación del clásico **juego Buscaminas**, desarrollada en **Python** durante el **primer semestre** de la carrera como ejercicio práctico de programación.

El juego se ejecuta completamente en **consola**, utilizando caracteres y emojis para representar el tablero, las minas y las acciones del jugador.  
El objetivo es descubrir todas las casillas seguras sin detonar una mina.

El proyecto pone en práctica conceptos fundamentales de programación como:
- Uso de funciones
- Listas bidimensionales (matrices)
- Condicionales y ciclos
- Manejo de entradas del usuario
- Lógica de juego y control de estados

---

## Funcionalidad

- Generación automática del tablero
- Colocación aleatoria de minas
- Cálculo de pistas (número de minas vecinas)
- Movimiento del jugador con teclado (`W`, `A`, `S`, `D`)
- Descubrir casillas
- Marcar y desmarcar posibles minas
- Expansión automática de zonas vacías
- Detección de victoria y derrota

---

## Controles

- `W`, `A`, `S`, `D` → Moverse por el tablero  
- `M` → Descubrir una casilla  
- `B` → Marcar una casilla como mina  
- `V` → Quitar marca de mina  

---

## Tecnologías

- Python
- Programación estructurada
- Consola / Terminal

## Objetivo del proyecto

Aplicar los conocimientos básicos de programación adquiridos en el primer semestre, desarrollando un juego funcional que refuerce la **lógica algorítmica**, el manejo de estructuras de datos y la interacción con el usuario desde consola.

## Description (English)

This project is an implementation of the classic **Minesweeper game**, developed in **Python** during the **first semester** as a programming practice project.

The game runs entirely in the **console**, using characters and emojis to represent the board, mines, and player actions.  
The goal is to uncover all safe cells without triggering a mine.

This project applies fundamental programming concepts such as:
- Function usage
- Two-dimensional lists (matrices)
- Conditionals and loops
- User input handling
- Game logic and state control

---

## Features

- Automatic board generation
- Random mine placement
- Neighbor mine hints calculation
- Player movement using keyboard (`W`, `A`, `S`, `D`)
- Cell revealing
- Mine marking and unmarking
- Automatic expansion of empty areas
- Win and lose detection

---

## Technologies

- Python
- Structured programming
- Console-based application

---

## Project Goal

To apply and reinforce basic programming knowledge acquired during the first semester by developing a functional game that strengthens **algorithmic thinking**, data structure handling, and user interaction through the console.
