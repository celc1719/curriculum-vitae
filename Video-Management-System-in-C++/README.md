# Sistema de Gestión de Videos en C++

## Descripción (Español)

Este proyecto consiste en un sistema de gestión de videos desarrollado en **C++**, utilizando **Programación Orientada a Objetos**.  
El sistema administra **películas y capítulos de series**, los cuales se cargan desde un archivo de texto y se gestionan mediante un menú interactivo en consola.

El programa permite:
- Mostrar el catálogo completo de videos
- Calificar películas y capítulos
- Filtrar videos por **calificación mínima**
- Filtrar videos por **género**

El proyecto está enfocado principalmente en el **diseño teórico y documental**, demostrando el uso de:
- Herencia y polimorfismo
- Clases abstractas
- Sobrecarga de operadores
- Manejo dinámico de memoria
- Uso de `vector`, `ifstream` y `string`

---

## Description (English)

This project is a **video management system** developed in **C++** using **Object-Oriented Programming** principles.  
The system manages **movies and TV series episodes**, which are loaded from a text file and controlled through an interactive console menu.

The program allows the user to:
- Display the full video catalog
- Rate movies and episodes
- Filter videos by **minimum rating**
- Filter videos by **genre**

The project is mainly **theoretical and documentary**, focusing on demonstrating:
- Inheritance and polymorphism
- Abstract classes
- Operator overloading
- Dynamic memory management
- Use of `vector`, `ifstream`, and `string`
