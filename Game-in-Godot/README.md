# Cosmo Rat – Propuesta de Videojuego

## Descripción (Español)

**Cosmo Rat** es una **propuesta de videojuego** desarrollada como proyecto académico utilizando el motor **Godot**.  
Este repositorio **no incluye el código fuente**, ya que el desarrollo se realizó en otra computadora. Sin embargo, se conserva la **documentación y presentación del proyecto**, incluyendo capturas del juego y el diseño conceptual.

El proyecto presenta:
- Historia y narrativa del juego
- Diseño de personajes
- Concepto de jugabilidad
- Estilo visual y escenarios
- Público objetivo y plataformas previstas

El juego sigue la historia de **Kiter**, un ratón que es secuestrado por alienígenas y llevado a un planeta desconocido, donde debe sobrevivir, esquivar enemigos y encontrar la forma de escapar.

Este proyecto es principalmente **conceptual y documental**, demostrando habilidades en:
- Diseño de videojuegos
- Creación narrativa
- Diseño de personajes
- Planeación de jugabilidad
- Presentación de proyectos

## Tecnologías

- Documentación y presentación visual

## Objetivo

Desarrollar y presentar una propuesta sólida de videojuego aplicando conceptos de diseño, narrativa y planeación de jugabilidad dentro de un proyecto académico.

## Description (English)

**Cosmo Rat** is a **video game proposal** developed as an academic project using the **Godot** engine.  
This repository **does not include source code**, as the development was carried out on another computer. However, the project’s **documentation and presentation** are preserved, including game screenshots and conceptual design.

The project presents:
- Game story and narrative
- Character design
- Gameplay concept
- Visual style and environment
- Target audience and intended platforms

The game follows the story of **Kiter**, a mouse who is abducted by aliens and taken to an unknown planet, where he must survive, avoid enemies, and find a way to escape.

This project is mainly **conceptual and documentary**, demonstrating skills in:
- Game design
- Narrative creation
- Character design
- Gameplay planning
- Project presentation
