# Evidence 1 – Technical Report: ABS System & Computational Modeling

## Español

Este proyecto académico corresponde a un **reporte técnico** desarrollado para la materia *Modelación de sistemas mínimos y arquitecturas computacionales*.

El trabajo analiza el **sistema de frenado ABS (Anti-lock Braking System)** desde una perspectiva de **sistemas ciberfísicos**, combinando conceptos de ingeniería automotriz, arquitectura computacional y modelación de datos.

El reporte se divide en varias etapas donde se:
- Describe el funcionamiento del sistema ABS
- Analizan posibles fallas y variables críticas
- Relaciona el sistema ABS con el concepto de sistemas ciberfísicos
- Introduce el uso de modelos computacionales y simulaciones
- Explica, a nivel conceptual, el manejo de datos y operaciones básicas en una arquitectura educativa (MARIE)

### Temas abordados
- Sistema de frenado ABS
- Sensores, actuadores y unidad de control (ECU)
- Variables físicas y electrónicas del sistema
- Sistemas ciberfísicos vs arquitectura de Von Neumann
- Modelación y simulación computacional
- Manejo de datos y operaciones básicas en MARIE
- Importancia de la optimización y el análisis algorítmico

## English

This academic project is a **technical report** developed for the course *Modeling of Minimal Systems and Computational Architectures*.

The work analyzes the **Anti-lock Braking System (ABS)** from a **cyber-physical systems perspective**, combining concepts from automotive engineering, computer architecture, and data modeling.

The report is structured in multiple stages that:
- Explain how the ABS system works
- Analyze common failures and critical variables
- Relate ABS to cyber-physical systems
- Introduce computational modeling and simulation concepts
- Conceptually describe data handling and basic operations using the MARIE educational architecture

### Topics Covered
- Anti-lock Braking System (ABS)
- Sensors, actuators, and Electronic Control Unit (ECU)
- Physical and electronic system variables
- Cyber-physical systems vs Von Neumann architecture
- Computational modeling and simulation
- Data handling and basic operations in MARIE
- Importance of optimization and algorithmic analysis
