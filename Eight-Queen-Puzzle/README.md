# 8 Queens Puzzle

## Español

Este proyecto académico presenta un **análisis teórico del problema de las 8 reinas**, un clásico de las ciencias de la computación y de los problemas de satisfacción de restricciones (CSP).

El objetivo del problema es colocar **ocho reinas en un tablero de ajedrez 8×8** de forma que ninguna ataque a otra, lo cual implica que no pueden compartir fila, columna ni diagonal.

El trabajo se centra en:
- Explicar el problema desde un enfoque algorítmico
- Analizar la complejidad del reto
- Comparar diferentes estrategias de solución
- Destacar la importancia de las estructuras de datos para mejorar el rendimiento


### Temas abordados
- Historia del problema de las 8 reinas
- Problemas de satisfacción de restricciones (CSP)
- Algoritmo de backtracking
- Uso de estructuras de datos para optimización
- Comparación entre métodos ingenuos y optimizados

## English

This academic project presents a **theoretical analysis of the 8 Queens Puzzle**, a classic problem in computer science and constraint satisfaction problems (CSP).

The goal of the puzzle is to place **eight queens on a standard 8×8 chessboard** so that none of them attack each other, meaning no two queens share the same row, column, or diagonal.

This work focuses on:
- Explaining the problem from an algorithmic perspective
- Analyzing its computational complexity
- Comparing different solution strategies
- Highlighting the importance of data structures in performance optimization

### 🧠 Topics Covered
- History of the 8 Queens Puzzle
- Constraint Satisfaction Problems (CSP)
- Backtracking algorithm
- Data structures for optimization
- Comparison between naive and optimized approaches
